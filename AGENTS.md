## Commands

- `npm run dev` — Turbopack dev server at http://localhost:3000
- `npm run build` — production build
- `npm run start` — production server
- `npm run lint` — ESLint over the whole project
- `npx tsc --noEmit` — typecheck (no separate typecheck script; `tsconfig` sets `noEmit: true`)

No test runner or test files are configured.

## Entrypoints & aliases

- App Router: `src/app/layout.tsx` (root), `src/app/page.tsx` (home)
- Import alias `@/*` → `./src/*` (tsconfig paths)
- shadcn/ui aliases (from `components.json`): `@/components`, `@/components/ui`, `@/lib`, `@/lib/utils`, `@/hooks`

## Framework quirks (Next.js 16 + Turbopack + React Compiler)

- `next.config.ts` enables `reactCompiler: true`, `cacheComponents: true`, `partialPrefetching: true`; Tailwind CSS v4 via `@tailwindcss/turbopack`.
- `next/font/google` is used for fonts (`Josefin_Sans` in `layout.tsx`).
- **Blocking prerender:** `new Date()` and other unstable/time-varying values are not allowed during server prerendering. Fix with `"use client"`, `"use cache"`, or dynamic data access before the call. See `src/components/Footer.tsx` (current-time fix applied).
